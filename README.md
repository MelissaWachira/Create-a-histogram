Histogram Generator
A Python script that generates a histogram to visualize the distribution of a dataset.

About
Data visualization is a core part of data analysis. This project demonstrates how to create clean, readable histograms in Python using matplotlib one of the most fundamental visualization skills for any data analyst.

Features

Reads a dataset and plots its distribution as a histogram
Customizable bins, labels, and titles
Clean and readable chart output


Tech Stack

Language: Python
Libraries: matplotlib, numpy


How to Run

Clone the repository:

bash   git clone https://github.com/MelissaWachira/Create-a-histogram.git
   cd Create-a-histogram

Install dependencies:

bash   pip install matplotlib numpy

Run the script:

bash   python lisa.py

Sample Output
The script generates a histogram showing data frequency distribution across defined intervals (bins), making patterns in the data immediately visible.
